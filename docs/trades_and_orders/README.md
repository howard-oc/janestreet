# Trades and Orders v1

This folder documents the StoneX / City Index **Trades and Orders v1** HTTP services used by the `augmenttrade` project.

## Contents
- `get_order.md` – `GetOrder` endpoint
- `cancel_order.md` – `CancelOrder` endpoint
- `order.md` – `Order` (place order) endpoint
- `get_open_position.md` – `GetOpenPosition` endpoint
- `list_open_positions.md` – `ListOpenPositions` endpoint
- `list_stop_limit_order_history.md` – `ListStopLimitOrderHistory` endpoint
- `get_active_stop_limit_order.md` – `GetActiveStopLimitOrder` endpoint
- `list_active_stop_limit_orders.md` – `ListActiveStopLimitOrders` endpoint
- `list_trade_history.md` – `ListTradeHistory` endpoint
- `trade.md` – `Trade` (place trade) endpoint
- `update_order.md` – `UpdateOrder` endpoint
- `update_trade.md` – `UpdateTrade` endpoint
- `list_active_orders.md` – `ListActiveOrders` endpoint

Individual files can be filled out progressively as we integrate each endpoint into the client.
