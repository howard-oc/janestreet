# Price History

This folder documents the StoneX / City Index **Price History** HTTP services used by the `augmenttrade` project.

## Contents
- `price_history.md` – `GetLatestPriceBars` (barhistory)
- `price_history_after.md` – `GetPriceBarsAfterDate` (barhistoryafter)
- `price_history_before.md` – `GetPriceBarsBeforeDate` (barhistorybefore)
- `price_history_between.md` – `GetPriceBarsBetweenDates` (barhistorybetween)
- `price_ticks_latest.md` – `GetLatestPriceTicks` (tickhistory)
- `price_ticks_after.md` – `GetPriceTicksAfterDate` (tickhistoryafter)
- `price_ticks_before.md` – `GetPriceTicksBeforeDate` (tickhistorybefore)
- `price_ticks_between.md` – `GetPriceTicksBetweenDates` (tickhistorybetween)

Each document describes the endpoint path, parameters, response shape, and typical usage patterns (for example, getting yesterday's close, performing incremental updates, or retrieving event‑window data).
