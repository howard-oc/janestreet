# Market v2

This folder documents the StoneX / City Index **Market v2** HTTP services used by the `augmenttrade` project.

## Contents
- `get_full_search_with_tags_v2.md` – `GetFullSeachWithTags v2`
- `get_market_information_v2.md` – `GetMarketInformation v2`
- `get_market_information_extended_v2.md` – `GetMarketInformationExtended v2`
- `list_market_information_v2.md` – `ListMarketInformation v2`
- `save_market_product_information_v2.md` – `SaveMarketProductInformation v2`
- `get_market_spread_v2.md` – `GetMarketSpread v2`
- `tag_lookup_v2.md` – `TagLookup v2`

Each document can describe the endpoint path, parameters, response DTO and usage patterns (for example, populating market grids or resolving tag IDs).
