# Messages – News

This folder documents the StoneX / City Index **News** HTTP services under the `Messages` category.

## Contents
- `get_market_report_headlines.md` – `GetMarketReportHeadlines`
- `get_market_reports.md` – `GetMarketReports`
- `get_news.md` – `GetNews`
- `get_news_headlines.md` – `GetNewsHeadlines`
- `get_story.md` – `GetStory`
- `search_market_reports.md` – `SearchMarketReports`
- `search_news.md` – `SearchNews`

These endpoints provide access to market and news headlines, full stories, and searchable news content to support UI displays and analytics within `augmenttrade`.
